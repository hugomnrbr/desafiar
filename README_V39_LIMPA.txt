QUIZUP v39.0.0 - PACOTE LIMPO

Use este pacote como uma instalação limpa do projeto.

1. Envie os arquivos do projeto para o GitHub.
2. No Supabase, execute SOMENTE o arquivo:
   quizup_v39_0_MIGRATION_COMPLETA.sql
3. Esta migration é idempotente: pode ser executada mesmo se algumas tabelas, policies ou triggers já existirem.
4. Não é necessário executar os SQLs de versões anteriores separadamente.
5. Mercado Pago permanece desativado até ser configurado/ativado pelo administrador.

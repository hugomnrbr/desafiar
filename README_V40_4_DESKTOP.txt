QuizUp v40.4 — Desktop + Mobile responsivo

Esta versão mantém a experiência mobile existente e adapta o aplicativo para computadores.

Desktop (>= 900px):
- navegação inferior vira barra lateral fixa;
- conteúdo ocupa a tela com largura máxima adequada;
- loja e categorias usam mais colunas;
- perfil, ranking, notícias, amigos e conquistas aproveitam o espaço;
- partida e fila ficam maiores, mantendo avatar, moldura e título;
- painel administrativo usa a largura completa do monitor.

Mobile (< 600px):
- mantém a navegação e o layout mobile existentes.

Nenhuma alteração de banco/SQL é necessária apenas para esta adaptação responsiva.
